# Screenshot plan (Apple & shared with Google — see store/google/screenshots_plan.md)

Per spec §115: screenshots must show the real product, and read as
genuine marketing material, not raw UI dumps. Capture on-device (or
simulator/emulator at required resolutions) once content is at release
scope. Suggested shot list, in order:

1. **Home** — horse hero art + Hijaz mountain backdrop, Solo/Family/
   Daily Challenge/Progress buttons visible. Communicates the whole
   concept in one frame.
2. **Board mid-game** — the Makkah↔Madinah journey board, 2+ horse
   tokens placed, a protected square visible. Communicates "this is a
   real board game," not just a quiz.
3. **Question card** — a question mid-answer with the source citation
   visible. This is the app's core promise (spec §27) and its most
   important screenshot after Home.
4. **Family mode / player setup** — team color + symbol + horse coat
   picker, 2-4 name fields. Communicates the family angle.
5. **Progress screen** — stats grid. Communicates depth/replayability.
6. **Daily Challenge** — the 5-question flow. Communicates the daily
   habit hook.

Required sizes to produce at submission time (verify against current
App Store Connect requirements, which change): iPhone 6.9", iPhone 6.5",
iPad 13" — see spec §111 (current platform rules always override this
document).
